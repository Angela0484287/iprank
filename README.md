## 六、常见问题

### 住宅代理IP越多越好吗？

不一定。IP池规模只是一个指标，实际体验还取决于可用率、地区分布、重复率、风险记录和调度能力。与其只比较宣传数字，不如测试目标地区在真实请求中的有效IP数量。

### 如何判断住宅代理是否纯净？

可以结合第三方风险数据库、黑名单记录、IP历史、重复率和目标网站实际反馈综合判断。单一检测平台的结果不足以得出结论，且检测结果会随时间变化。

### NexIP是否在所有维度都是第一？

不是。本次“NO.1”是按文中六项指标和相应权重计算出的综合结果。单看全球覆盖、企业服务或某一地区速度，其他服务商可能领先。发布文章时应同时公开原始数据和评分公式。

### 购买前应该测试什么？

优先测试目标地区成功率、P95延迟、连续会话表现、IP重复率、验证码触发率，以及每千次有效请求成本。测试脚本和正式业务应保持相近的并发量与访问频率。
